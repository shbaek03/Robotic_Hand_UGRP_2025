# Robotic_Hand_UGRP_2025
Robotic hand kit for UGRP, 2025
## File Description
- The attached files are robotic hand control library using visual hand pose recognition.
- The motors are controlled by I2C PWM controller & Arduino.
## Robotic Hand Model
- Kit module desing using ONSHAPE
- STL file is attached
## Award
- This project is awarded the first place of the POSTECH Undergraduate Research Program (UGRP) in 2025.
